# Aula 12 — Circunferências: conceitos e ângulos

Aula interativa MatMov sobre circunferências, arcos, radianos e ângulos centrais, inscritos e circunscritos.

**[Abrir a aula completa no GitHub Pages](https://guilhermealj.github.io/aula-circunferencias-revisao/)**

[Versão para revisão docente](https://guilhermealj.github.io/aula-circunferencias-revisao/aula12-revisao.html)

## Uso

Use as setas para navegar, o índice para escolher uma tela e Consulta para leitura contínua. As soluções são reveladas progressivamente. O botão Professor abre o controle de participação manual.

A aula é um HTML autônomo e também funciona offline. As medidas inseridas no laboratório do π ficam no navegador do professor; não são sincronizadas entre alunos.

## Participação no Meet

A integração opcional com o Meet requer a [extensão MatMov](matmov-extensao.zip), instalada pelo professor no Chrome ou Edge. Descompacte o ZIP e carregue a pasta da extensão em modo desenvolvedor. O assistente de análise é um serviço local separado e não está hospedado no GitHub Pages. A integração não foi ensaiada nesta publicação com uma turma real.
